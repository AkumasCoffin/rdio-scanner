A patch is a set of talkgroups on one system that carry the same conversation. The same transmission arrives once per talkgroup; only one call is kept, filed under the primary and marked as patched with the whole set — so it plays once, shows PATCH on the display, reaches anyone listening to any of its talkgroups, and goes downstream like any other patched call. Collapsing uses the duplicate detection time frame from Options, and happens even when duplicate detection is switched off.
