A patch is a set of talkgroups on one system that carry the same conversation. The same transmission arrives once per talkgroup with the same timestamp; only one call is kept, filed under the primary and marked with the talkgroups it was actually received on — so it plays once, shows PATCH on the display, reaches anyone listening to any of its talkgroups, and goes downstream like any other patched call. Copies are matched by their exact timestamp, independent of the duplicate detection settings.
