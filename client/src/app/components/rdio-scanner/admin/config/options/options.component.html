LED

Dual Color LED
Allow a second LED color per system and talkgroup. Systems and talkgroups get a second color selector, and the main screen LED becomes a two-color lightbar.

Wig-Wag LED
The dual LED's halves alternate like a police lightbar while a call plays.

Auto Populate
Globaly allows the automatic creation of unconfigured systems and talkgroups.

Disable duplicate audio file detection.

New incoming calls will be rejected if a call already exists in the database with a start time of +/- this delay in milliseconds.

Prune Days
Prune the database for data older than the specified number of days. Also bounds the listener-statistics history. Set to 0 to disable.

Logs & Statistics

Log Prune Days
Prune the event logs older than the specified number of days, independently of Prune Days. Leave blank or 0 to disable. Defaults to 7.

Log prune days is invalid

Log Prune Count
Hard cap on the number of event-log rows kept (newest first), enforced hourly on top of Log Prune Days. Leave blank or 0 to disable. Defaults to 250000.

Log prune count is invalid

Show Listener Statistics
Show listener-count history charts on the statistics panel for all users. Admins always see them on the admin statistics dashboard.

Search Patched Talkgroups
Search for patched talkgroups when using the search panel. Be aware this has a negative impact on search response time.
